## CV Output Formatting Requirements

- Use a clean professional CV format.

---

## Important Rules

1. Use **only the information I provide**.
2. Do **not** add fake experience, fake certifications, fake company names, fake achievements, or fake technical skills.
3. If information is **missing**, write `[Add this information]` instead of guessing.
4. If information is **weak**, improve the wording professionally — but do not exaggerate.
5. Every bullet point must start with a **strong action verb**.
6. Use this bullet formula where possible:

   > **Action Verb** + Task/Project + Tool/Technology + Result, Output, or Learning

7. Keep the CV **ideally 1 page**. Use 2 pages only if the information is strong and necessary.
